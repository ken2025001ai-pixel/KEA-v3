## 问题背景

Phase 6 当前将 `DIAGRAMS_DIR` 和 `OBJECTS_DIR` 路径直接传给 extract-logic subagent，由 subagent 自己读取原始 Mermaid 文件和所有对象文档。存在两个问题：

1. **subagent 自己读 DIAGRAMS_DIR**：与 Phase 5 改造前一样的问题，subagent 被迫承担确定性解析工作，且 `kea mermaid` 之前不支持 `.md` 目录（已修复）
2. **subagent 自己读 OBJECTS_DIR**：Phase 5 输出了 N 个对象文件，subagent 在写伪代码时需要知道可用对象和属性名称，逐文件读取既慢又不透明——`kea parse` 已能批量解析目录并输出属性清单，完全可以替代

**设计原则来源**：CLAUDE.md — "Controller 负责准备上下文，不让 subagent 自己找文件"

## 为什么不为伪代码生成构建专用工具

伪代码生成涉及两类工作：
- **结构映射**（Mermaid 节点 → 伪代码框架，确定性）：工具可以做
- **语义填充**（参数名称、assert 条件、属性级引用，须理解业务含义）：只能 LLM

结构映射占约 30% 工作量，语义填充占 70%。`mermaid-spec.md` 已明确规范节点语义映射，LLM 按规范直接生成伪代码比工具骨架 + LLM 填充更简洁，且 LLM 在结构翻译上本来就可靠。

因此，**Phase 6 不需要伪代码生成工具**，只需和 Phase 5 一样做结构化上下文预处理。

### 2.2 Step 1 重写（替换整节）

```markdown
## Step 1: Read inputs

Read `FLOWCHART_CANDIDATES` — structured flowchart text generated by Phase 6
using `kea mermaid`. Each file entry maps to one logic document. Nodes (with
type) and edges provide the pseudocode structure.

Read `OBJECT_REGISTRY` — the complete list of confirmed objects with their
properties, generated by Phase 6 using `kea parse`. Use this as the sole
source for:
- `[[链接]]` validity: only link to objects listed here. If an object is not
  in OBJECT_REGISTRY, do NOT `[[link]]` it — mark it as "待提取对象" instead.
- Attribute-level pseudocode: reference `ObjectName.propertyName`
  (e.g., `采购订单.状态`), not just `ObjectName`.

Then read files in `SUMMARY_PATHS` for supplementary business context —
process purpose, business rules, edge cases not visible in flowcharts.

**Do NOT read files from DIAGRAMS_DIR or OBJECTS_DIR** — the tools have
already done that. Your role is semantic judgment and document generation,
not file parsing.

Map node types to pseudocode constructs (per mermaid-spec.md):

| Node type | Shape | Pseudocode construct |
|---|---|---|
| `action` | `[矩形]` | `call_action("动作名", {params})` |
| `activity` | `(圆角矩形)` | 展开为多个子步骤 |
| `decision` | `{菱形}` | `if condition: / else:` — 必须有 Yes/No 两个分支 |
| `subprocess` | `[[双框]]` | `result = call_logic("子流程名", {params})` |
| `recursive` | `{{双花括号}}` | `for item in collection:` |
| START | `((开始))` | `function name(inputs):` |
| END | `((结束))` / `>结束]` | `return {...}` |
```
